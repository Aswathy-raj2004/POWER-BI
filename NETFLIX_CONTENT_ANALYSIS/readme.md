# 🎬 Netflix Content Analytics Dashboard | Power BI

An interactive **Netflix Content Analytics Dashboard** built using **Microsoft Power BI** to explore content, performance, audience engagement, and individual title-level information.

The project transforms a Netflix content dataset into an interactive business intelligence dashboard using **Power Query, DAX, data modeling, KPIs, interactive slicers, navigation buttons, and visual analytics**.

---

## 📌 Project Overview

The objective of this project is to analyze Netflix-style content data and create an interactive dashboard that allows users to:

- Explore the Netflix content catalog
- Compare Movies and TV Shows
- Analyze genres, countries, and languages
- Identify top-performing titles
- Analyze ratings and subscriber impact
- Explore individual title details
- Examine content performance trends
- Generate forecast projections based on historical trends

The dashboard is designed to provide both **high-level business insights** and **detailed title-level analysis**.

---

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query** – Data cleaning and transformation
- **DAX** – Calculated columns and measures
- **Data Modeling** – Relationships between tables
- **Power BI Visualizations**
- **Excel** – Dataset preparation

## 📊 Dashboard Pages

### 1️⃣ Netflix Overview

The overview page provides a high-level summary of the dataset.

#### Key KPIs

- 🎬 Total Titles
- 🎥 Movies
- 📺 TV Shows
- ⭐ Average Rating
- 👁 Total Views
- 👥 Subscribers Gained

#### Key Analysis

- Titles by year
- Movies vs TV Shows
- Top genres
- Language distribution
- Content by decade

---

### 2️⃣ Content Analysis

This page focuses on content performance and audience response.

#### Visualizations

- 🏆 Top 10 Titles by Views
- 🌍 Content by Country
- ⭐ Rating Distribution
- 👥 Subscribers Gained by Genre
- 📈 Views Trend and Forecast

The Top 10 Titles visualization is presented as a table to allow users to compare title-level performance.

---

### 3️⃣ Title Details

This page provides detailed information about an individual title.

Users can select a title using an interactive slicer.

#### Title Information

- Content Type
- Genre
- Director
- Cast
- Language
- Country
- Release Year
- Runtime
- Rating
- Age Rating

#### Performance KPIs

- 👁 Views
- ⭐ Rating
- 👥 Subscribers Gained
- 💰 Production Budget
- 💵 Revenue Impact

The page also includes interactive navigation buttons to move between dashboard pages.

---

## 🔄 Data Preparation

Power Query was used to prepare the dataset for analysis.

Major transformation steps included:

- Removing and handling inconsistent values
- Standardizing column names
- Cleaning content types
- Preparing genre and language fields
- Formatting release years and dates
- Standardizing runtime information
- Creating rating categories
- Preparing analytical fields
- Structuring data for Power BI relationships
